# Summarise prepared epikinetics model data

Summarise prepared epikinetics model data

## Usage

``` r
# S3 method for class 'epikinetics_data'
summary(object, ...)
```

## Arguments

- object:

  An `epikinetics_data` object.

- ...:

  Reserved for future methods.

## Value

A list of counts, ranges, mappings, censoring information, formula
metadata, and design-matrix dimensions.
